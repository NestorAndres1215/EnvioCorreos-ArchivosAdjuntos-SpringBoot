# 📧 Sistema de Envío de Correos

Aplicación web que permite enviar correos electrónicos con archivos adjuntos mediante un formulario.

El proyecto está dividido en:

- **Frontend:** Vue 3 + Vite
- **Backend:** Spring Boot
- **Alertas:** SweetAlert2
- **HTTP Client:** Axios

---

# 🚀 Tecnologías usadas

### Frontend
- Vue 3
- Vite
- Vue Router
- Axios
- SweetAlert2
- FontAwesome

### Backend
- Spring Boot
- Jakarta Mail
- Lombok
- Validaciones con Jakarta Validation
